## Status meanings

- `TODO`: ready for implementation after the stamped-code preflight.
- `IN PROGRESS`: an executor is actively implementing and validating it.
- `DONE`: implementation and the plan's mechanical and feel checks have passed.
- `STALE`: cited ownership or APIs no longer match the stamped commit; reconcile before execution.
